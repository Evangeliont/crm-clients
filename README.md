## CRM система клиентов

### Требования

- **Node.js**: версия **14+** (рекомендуется актуальная LTS).
- **npm**: установлен вместе с Node.js.

### Установка зависимостей

- **Корень проекта (фронтенд + оркестрация):**

```bash
npm install
```

- **Бэкенд (для запуска тестов, если нужно):**

```bash
cd crm-backend
npm install
```

### Запуск в режиме разработки

- **Запустить фронтенд и бэкенд одной командой:**

```bash
npm run dev
```

- **Или по отдельности:**

```bash
# в корне проекта
npm run dev:backend   # Node.js сервер на http://localhost:3000
npm run dev:frontend  # Webpack Dev Server на http://localhost:8080
```

Фронтенд (Webpack Dev Server) поднимается на `http://localhost:8080` и проксирует запросы к API по пути `/api` на бэкенд `http://localhost:3000`.

### Сборка проекта (production)

- **Собрать фронтенд:**

```bash
npm run build
```

Собранный бандл попадает в папку `dist` (минифицирован и обфусцирован).  
Статические файлы стилей и изображений берутся из директорий `css`, `libs`, `img` (как в шаблоне `index.html`).

### Тестирование бэкенда

```bash
cd crm-backend
npm test
```

Тесты написаны на **Jest** и проверяют корректность REST API (CRUD, валидация, поиск и т.д.).

### Структура проекта

- **`src/`**: исходники фронтенда.
  - **`src/main.js`**: точка входа фронтенд-приложения.
  - **`src/modules/CrmApp.js`**: корневой класс приложения (инициализация и оркестрация).
  - **`src/modules/api/ClientsApi.js`**: класс для работы с REST API клиентов.
  - **`src/modules/ui/Header.js`**: класс шапки приложения (логотип + поиск).
  - **`src/modules/ui/ClientsSection.js`**: класс секции с таблицей клиентов, модалками, сортировкой и валидацией.
- **`crm-backend/`**: backend-сервер и его тесты.
  - **`crm-backend/index.js`**: HTTP-сервер и реализация REST API.
  - **`crm-backend/index.test.js`**: Jest-тесты API.
  - **`crm-backend/README.md`**: подробная документация по методам API и структуре клиента.
- **`css/`, `libs/`, `img/`**: стили, normalize.css и статические изображения для фронтенда.
- **`webpack.config.js`**: конфигурация Webpack (dev server, сборка, минификация и обфускация).
